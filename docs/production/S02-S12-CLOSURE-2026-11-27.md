Critical findings carried into the next tranche:

1. The point-in-time Subscription funding verification must become a durable
   Billing claim before activation can be approved. All refund paths must respect
   that claim; cancellation must quiesce outstanding entitlement use before release.
2. Communications/Reporting still subscribe to `booking.confirmed.v1`, while the
   Booking producer emits `booking.created.v1`. Production routing and legitimate
   consumers must be reconciled. A test observer binding does not prove this.
3. Owner-to-owner private transport configuration is inconsistent. Railway private
   transport needs one explicit policy, with scope-bound service credentials.
4. Staging needs broker identities/topology, owner migrations, deployed APIs/workers,
   real onboarding/configuration, monitoring and a restore exercise before S10/S11.
