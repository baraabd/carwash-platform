4. Execute security H01..H12, state H13..H22, fault H23..H32, performance H33..H35,
   all-app H36..H40 and rehearsal H41..H43 on exact combined source. Retest owner
   corrections before latest candidate/target and freeze gates H44..H45.

These are queued child scopes, not started extra sprints or permission to implement
other owners. A peer proposal or moving branch cannot become an accepted provider.

## State and monetary races

Synchronize actual HTTP calls/processes and transactions at the last slot,
entitlement, funds/promotion and assignment boundaries. Exercise current revision,
actor authority and expired/stale states, repeated payment/refund/reviewer decisions,
conflicting idempotency fingerprints and lost replies after commit. Capture original

financial confirmation, custody and benefit facts; one allowed effect and completed

expired capacity. Server verification/audit remains required for Cash, ShamCash and
Syriatel Cash under each accepted policy; Paymera disposition remains unresolved.
No live provider/money/refund authorization is inferred.

## Fault boundaries and reconciliation

| Boundary           | Required interruption and durable observation                                                                                                                                                           |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Producer DB        | Before/after commit, pool wait, transaction stall and cancellation; retained original operation and no late mutation into the next reset.                                                               |
| Outbox/broker      | After lease, before publish, confirm loss, after confirm/before mark, final permitted lease crash, delayed tail and competing reclaim; inspect original IDs and explicit pending/exhausted disposition. |
| Consumer DB/ACK    | Before/after effect plus inbox commit and before/after ACK; changed-byte conflict and unrelated unique constraint must not be silently ACKed as duplicate.                                              |
| Provider           | Verification/refund request accepted with response lost, timeout, restart and reconciliation; one authorized original monetary effect.                                                                  |
| Storage/media      | Acquire/upload/process/finalize/read interruptions; one original finalized object, quarantine and current object/purpose authorization.                                                                 |
| Network/projection | Partition, reorder, reconnect, replay and checkpoint catch-up; unavailable is not empty/zero/paid and current revisions/privacy suppression survive.                                                    |
| Pressure           | Delayed confirms, ignored publish drain, stalled connect, poison hot retry, readiness storms, pool waiters and queue growth; bounded resource use plus authoritative reconciliation.                    |

Use predeclared injection seams and independent cleanup deadlines. Register recovery
before destructive work; stop only owned workers, restore only owned dependencies,
await readiness and propagate every recovery error. Scope guards around awaits do
not cancel underlying operations that ignore the signal. Drain or retain committed
outcomes before a subsequent case can mutate/reset the same owned namespace.
