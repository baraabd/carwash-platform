E must freeze a real record with actual values for each link below. These semantic
field groups are proposals, not accepted DTOs, APIs or a populated evidence fixture.

1. **Accepted base and review:** BASE_W10/resulting target SHA/tree, published
   contract/client/event versions, approved full scope/design/policy, independent
   eligible review records and mandatory/affected gates on that source.

   parents/tree, gate run/attempt and protected artifact identifiers/digests;
   unchanged-ref check before authorized merge. GitHub's automatic test merge
   is not a declaration of E acceptance.
3. **Deployed artifacts:** source-bound app/service/worker/migration-job repository
   digests, actual registry pull/startup identity, immutable configuration and
   protected secret/key-policy references, accepted environment/namespace and
   independently recorded current runtime artifacts. No secret values in Git.

   compatible prior populated records/artifacts, separate runtime/migrator roles,
   E-approved accounts/resource slot/ports/DB/queue/object/browser/output scope.
5. **Action provenance:** original matrix/action/case ID; exact source-owner and
   schema/version; approved UI state/reference; current actor/session/object/
   purpose/guest/resource authorization; original operation/fingerprint/revision;
   actual persisted/audited outcome, source event/disposition and reconciled read.
6. **Actual command and oracle:** existing executed command/sanitized arguments,
   start/end/time source/exit/output checksum and protected evidence links;
   independent prior expected records/control totals/coverage and actual after
   results; DB/HTTP/broker/provider/browser/device versus fixture labels.
7. **Final decision:** every required action/example plus mandatory and affected
   gate status, source-owner failure/disposition/retest, measured recovery/loss/
   freshness versus approved limits, actual operator/reviewer acknowledgement and
   actual resulting-target checks. No silent missing/disabled row or scope cut.

Source and artifacts must agree on the environment actually executed. Unit
contracts cannot prove a DB constraint, broker replay, private bytes or a device.
