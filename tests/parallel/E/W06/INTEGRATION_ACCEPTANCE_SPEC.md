## Common execution and evidence contract

After an actual BASE_W06, run real owner-local DB/migrations/constraints/HTTP/
Identity/broker/provider-adapter tests against accepted contract versions in an
E-owned isolated run. Exclude production/provider accounts from destructive
fixtures. Use the approved Wallet holders and policies; no automatic customer
stored-value, payroll, recurring debit or marketplace plan is inferred.

For each family bind source/head/tree/latest target/candidate/run/environment,
test command and version, real versus fixture/provider-derived scope, authenticated
subject/service/object/purpose, original operation/event/child identity and
policy/revision. Use independent owner current reads/receipts/audit and broker
observations before/after faults to prove invariant and eventual convergence.
Record blocked/failed/skipped cases honestly and owned cleanup/recovery handles.
Retain only bounded redacted metadata in generic artifacts, never credentials,
private media/provider documents or full payloads. A race requires synchronized
concurrent real operations, not two sequential fixture calls.
