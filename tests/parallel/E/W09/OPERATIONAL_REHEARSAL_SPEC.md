# W09-E declarative operational rehearsal specification

All **34** families **BLOCKED_NOT_RUN**. This is a proposed acceptance specification,
not executable deployment/recovery tests or passed product evidence. Shared entry:
accepted complete/hardened BASE_W09, published owner contracts/artifacts/config,
prior supported populated state, actual intended staging/access/operating team,
preapproved numerical profiles and isolated resource/fixture/send authorization.

Each case retains exact source/tree/repository digests/config/migration/profile/run,
actual actor/environment/times and independent owner-local before/after/original-ID
oracles, redacted output, invariant/discrepancy and cleanup result. E coordinates
without cross-owner SQL/private DTO imports. No mock/fixture/reference boot, skip,
infrastructure constraint or written runbook closes a real drill. Missing tests
remain NOT_RUN with launch-blocking consequence; measured failures remain FAIL.

## Closure

Independent expected facts must predate the fault/restore, not derive solely from
restored data. Approved limits and definitions precede execution and cannot be
lowered after failure. Every required subcase and full action/state scope needs
current-source evidence. The parent remains NOT_STARTED/ENTRY_BLOCKED until entry,
then INTEGRATION_PENDING until all real drills pass and independent review is done.
No BASE_W10, production execution or automatic next task follows this proposal.
